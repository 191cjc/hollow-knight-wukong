# 孙悟空技能逻辑研究记录

记录日期：2026-10-23。研究对象为 4399 网页版《造梦西游4》，主程序 `v5870.swf`，配置包 `cg1_20261019_1.swf`。

## 可以从现有文件得到什么

动画素材可以提供姿势、动作时长、骨架和动画事件；技能配置可以提供关联子技能、移动与发射参数、Buff、命中范围和消耗。**完整逻辑还需要追踪主程序的 ActionScript 3 代码，以及对照原游戏表现。**

已针对火魔斩完成关键 AS3 类的反编译和调用追踪，证据保存在 `reference/flash/fire-demon/`，判定、公式及测算见 `docs/FIRE_DEMON_RESEARCH.md` 和 `tools/calculate_fire_demon.py`。其余技能仍未完成完整逻辑研究。`reference/flash/v5870_strings.txt` 仅是字节码常量池的字符串索引，不能当作完整源码。

现有 `skills.xml` 已包含 `skillScope`、`subSkillID`、`shootFrame`、`shootSpeedX`、`shootTime`、`attMax`、`attInterval`、`consumeMP`、`cd`、`myBuff`、`param` 等原始字段。生成的 `data/generated/skills.json` 保留字符串值，不提前把原始单位换算成 Unity 单位。

## 容易误判的地方

- DragonBones 标称 30 FPS，并不说明所有技能时钟、`shootFrame` 和命中采样都采用同一计时规则。
- `evtMohu_*` 等动画事件的实际用途要追调用代码，不能先标为命中帧。
- Buff 引用可能使用基础 ID；级别记录会追加两位等级后缀。查询时需要同时检查精确 ID 和相应等级记录。
- 97 条技能记录包含普攻、子技能、觉醒变体和附加形态，并非 97 招独立技能。
- `2011` 的角色配置有 `烈火轰雷 1311010`；目前只称附加形态，不凭资源 ID 猜其具体玩法名称。

## 下一轮研究的可验收结果

建议先选棍系的烈焰闪打通一次流程，选择仍可调整：

1. 从 AS3 追到技能选择、输入、角色状态以及 `shootFrame` / `shootTime` 的读取位置，记录源码位置和调用关系。
2. 核对 `60002` 的状态效果与失效条件，确认碰撞、受击和取消规则。
3. 用原游戏录像/逐帧观察验证前摇、冲刺、收招与命中时机。
4. 输出单独的技能规格，将“源游戏证据”“移植设计”“空洞骑士中的实际实现值”分别写清。
5. 在空洞骑士中先验证移动、墙体碰撞、结束时恢复控制，再接动画、伤害与音效。

Java / FFDec 已在本地工作区的 `work/build-tools/` 准备，用于只读分析，不进入 Mod 包。火魔斩的核心判定和基础伤害已具备代码依据；完整原游戏受击链的所有 Buff、装备与目标特殊规则，以及其他技能，仍不能声称完整复刻。
