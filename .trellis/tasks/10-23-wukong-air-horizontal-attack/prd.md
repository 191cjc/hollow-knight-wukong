# 孙悟空单段空中水平棍击

## Goal

在已提交并上传的孙悟空外观及地面四连击基线上，接入具有独立动画时序和命中窗口的单段空中水平棍击。

## Confirmed Scope

- 用户要求先提交当前工作区，再开始空中攻击；当前 main 已在 9517499 提交并同步 origin/main，工作区原为干净。
- 用户已明确选择“单段空中水平棍击”，使用现有 jumpAttack，保留原生上劈、下劈和下劈弹跳。不是仅换播放姿势：空中水平棍击应有与动作同步的受控原生命中窗口。
- 沿用 Hollow Knight 1.5.78.11833 / Modding API v77 / net472 基线，不改移动、重力、跳跃次数、存档及资源系统。
- 复用现有原生攻击事务、固定步同步、每窗口/受击者去重和取消接触列表清理。真实客户端仍不可用，自动检查与实机状态分开。

## Requirements

- A1：离地且非贴墙的水平普攻触发单段 jumpAttack，重复按键不形成空中连击、不缓存下一段；下一次攻击沿用正常冷却与输入门控，不因 10 tick 动作较短而缩短原生冷却。
- A2：依据实际预览将 10 tick 动作的移植半开命中窗口设为 [4,7)，范围倍率为 1.0；同一窗口每目标最多一次；不额外发送平行伤害或手动魂获取。
- A3：与原生骨钉/护符规则保持一致；Quick Slash 同步缩放动画和窗口。
- A4：落地、中断、受击、冲刺、场景/角色生命周期等关闭所属攻击并安全恢复，不污染后续地面四连击、空中重复攻击或方向攻击。
- A5：地面四连击行为保留；上/下劈、贴墙攻击及下劈弹跳沿用原生路径。
- A6：资源协议、运行时、测试、构建/打包与文档一致；发布为可审阅开发包，实机检查保持 pending。

## Acceptance Criteria

- [x] 实际生产核心测试覆盖空中单次/重复输入、时序窗口、去重、取消/落地与地空切换。
- [x] 最终清单包含空中攻击配置，源 jumpAttack 预览及窗口有审阅记录。
- [x] 完整构建、资源/包闭包、所有相关测试和全范围独立检查通过（28 Python / 19 C# / Release 0 警告错误）。
- [ ] 客户端测试：跳跃/下落中各次攻击、命中/护符/魂、落地和方向/下劈弹跳等实际行为；无客户端时保持未验收。

## Out of Scope

空中多段连击、独立方向棍法、下砸技能、滞空/升空机制、跑攻、主动技能、Windows 原生工具链重构、原作 AS3 逐帧复刻。

## Decisions and Authorization

用户已要求开始开发并在后续回复确认单段空中水平棍击范围；按该授权继续实现。原地面四连击仍保持原规格，不归档其待客户端验收事项。资源 schema 升级为 2 并要求 combat.air_attack，避免旧 DLL 默默忽略新行为。版本为 0.3.0-dev。具体执行与验证见 design.md、implement.md；客户端接受项保持未勾选。
